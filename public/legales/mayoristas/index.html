Condiciones para mayoristas y revendedores

Última actualización: 26 de noviembre de 2026

1. Registro y aprobación

Los precios mayoristas son para comercios y revendedores. Para acceder tenés que registrarte con los datos de tu negocio (incluido el CUIT). myluz revisa cada solicitud y puede aprobarla o rechazarla. Hasta que la cuenta esté aprobada, vas a ver los precios para público.

2. Precios mayoristas

4. Uso de la cuenta

La cuenta es personal del negocio registrado. No se pueden compartir el usuario ni los precios mayoristas con terceros. myluz puede suspender o dar de baja una cuenta si se usa en forma indebida o si los datos no son correctos.

5. Compras para reventa

Las compras hechas para revender o para integrar a tu actividad comercial no tienen derecho de arrepentimiento (Disposición 954/2025), pero sí garantía por defectos de fabricación.
